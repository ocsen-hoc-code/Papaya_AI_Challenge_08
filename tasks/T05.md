# T05: Normalize dates and amounts

## Description
Dates -> ISO `YYYY-MM-DD`: Buddhist-era years (>2400 -> minus 543), dd/mm for vi/th, English/Vietnamese/Thai month names, and an 'ambiguous' flag when unsure. Amounts: `1.500.000` (vi), `1,500.00` (en), Thai digits, currency symbols (VND, THB, USD and their signs).

## Acceptance criteria
- [x] Unit tests cover all formats above
- [x] Unparseable values return None instead of raising

## Notes
- Implemented in `src/medextract/normalize.py`; 116 tests in `tests/test_normalize.py` pass.
- Date ambiguity policy: a numeric date reads as dd/mm and as mm/dd. If only one reading is a real calendar date, use it with no flag (`03/15/2024` gives 2024-03-15). If both are valid and differ, use dd/mm. For `vi` and `th` that is the local convention, with no flag. For `en` or an unknown language, set `ambiguous=True` and report the dd/mm reading in `issue`. Thai-context 2-digit years are Buddhist (67 -> 2024); elsewhere 2-digit years are 20yy.
- Amount separators: when both `.` and `,` appear, the last one is the decimal mark. A repeated single separator is thousands. A single separator followed by exactly 3 digits is thousands (`1,500`, `1.500`), except after a lone `0` (`0.500` = 0.5). Any other digit count is decimal (`1,5` = 1.5).
- Placeholders such as `N/A`, `-`, `null` count as missing for every kind, not as text.
- Medication `quantity` is normalized to a float ("21 capsules" -> 21.0), so the unit is dropped.
- Lab `result` is always a string. Flags map H/L/N, arrows, Vietnamese and Thai words to high/low/normal. Any other flag is invalid.
- Text lists split on newline, `;`, `|`, `•` and `,`. Leading bullets and numbering are removed.
