# T11: Tolerant JSON parsing + retry

## Description
`json.loads`, then `json_repair`, then Pydantic validation; if it still fails, retry once with the error message. Strip code fences and surrounding text.

## Acceptance criteria
- [x] Unit tests for broken, truncated and markdown-fenced JSON

## Files
- `src/medextract/parsing.py`
- `tests/test_parsing.py`

## Notes
- Files: `parsing.py` (`extract_json`, `generate_structured`, `JSONParseError`), `tests/test_parsing.py` (25 tests, FakeBackend only).
- `extract_json`: strips `<think>` blocks (including a bare `</think>`), code fences and prose, then strict `raw_decode` from the first `{`, falling back to `json_repair` on the same text.
- `generate_structured`: retries use the original prompt plus the latest error. Timeouts and backend errors are not retried.
