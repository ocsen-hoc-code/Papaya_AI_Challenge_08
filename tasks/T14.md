# T14: Grounding against hallucination

## Description
With a text layer: fuzzy-match `value`/`evidence` against the text, and if there's no match, cut confidence sharply or set the value to null. For images: check that `evidence` is consistent with `value`.

## Acceptance criteria
- [x] Unit test: a fabricated value (absent from the text) gets low confidence or null

## Files
- `src/medextract/grounding.py`
- `tests/test_grounding.py`

## Notes
- Public API: `GroundingStatus`, `Grounding(status, score, detail)`, `text_layer_usable(text)`, `ground_field(kind, value, evidence, text_layer)`.
- Text layer: a text is unusable when it is empty, has more than 5% U+FFFD, has `(cid:N)` tokens over 10% of its characters, or has under 30% letters/digits/marks (Thai marks count as marks).
- Strings: exact substring gives `exact` (1.0); rapidfuzz `partial_ratio` >= 90 gives `fuzzy` (ratio/100); a quoted evidence snippet found in the text gives `partial` (0.6-0.7); otherwise `not_found` (score 0.05-0.25 by closeness). Long text values are checked sentence by sentence and aggregated.
- Amounts and quantities: any number token reads as the same value gives `exact`; else `not_found` (0.1). `1.500.000` and `15.750` read as thousands, `1,500.00`, `1.500,50` and `12.5` as decimals. Thai digits are converted first.
- Dates: ISO value. With matching quoted evidence (day, month, year agree; year may be Buddhist +543) gives `exact` 0.95 or `fuzzy` 0.85; disagreeing evidence gives `partial` 0.5. Without evidence, the day, month and year appearing anywhere gives `partial` 0.55 (two of them: 0.35); else `not_found` 0.1.
- Lists and structured kinds: each item's main string (`description`, `test_name`, `name`) and numeric sub-fields are grounded as leaves. Score is the mean; status is `exact`/`fuzzy` when all leaves are found, `partial` when some fail, `not_found` when all fail. Null sub-fields are skipped.
- Images (no usable text layer): `no_reference`. Missing evidence gives 0.4; evidence that supports the value gives 0.6; evidence that does not gives 0.2; partial support is interpolated. Null value gives `no_reference` 0.0.
- No dependency on `normalize.py`. The module has its own Thai-digit folding and number reader.
- Tests: 31 in `tests/test_grounding.py`, all passing.
