# T15: Confidence scoring

## Description
Combine the model's self-reported confidence, logprobs (when available), grounding, and normalization results (ambiguous dates lose points); null fields get confidence <= 0.1; classification confidence comes from the normalized scores of the 4 types.

## Acceptance criteria
- [x] Unit test: confidence differs between certain and uncertain fields

## Files
- `src/medextract/confidence.py`
- `tests/test_confidence.py`

## Notes
- Public API: `span_token_prob(gen, start, end)`, `find_value_span(text, field_name)`, `field_confidence(*, kind, value, model_confidence, grounding, normalized_valid=True, ambiguous=False, token_prob=None)`, `classification_confidence(scores)`.
- Formula, with b = model confidence (default 0.7):
  1. Empty value gives `min(b or 0.05, 0.1)`.
  2. Exact match lifts b to `b + 0.5 * max(0, 0.98 - b)`.
  3. Factor g: exact 1.0, fuzzy 0.9, partial 0.75, no_reference `0.6 + 0.25 * grounding.score`, not_found 1.0 (then capped).
  4. c = b' * g; token_prob gives `c *= 0.5 + 0.5 * token_prob`; ambiguous gives `c *= 0.7`.
  5. Caps: not_found and `normalized_valid=False` give c <= 0.3. Round to 2 decimals, clamp to [0, 1].
- Sample outputs: exact 0.96, fuzzy 0.85, partial 0.71, image without evidence 0.66, ambiguous date 0.66, invalid date 0.30, not_found 0.30, null 0.10.
- `span_token_prob` takes the minimum probability over tokens overlapping the span. It aligns `extra["token_texts"]` to `gen.text` by sequential search and returns None if the pieces, logprobs or alignment are missing.
- `find_value_span` returns the inner span of strings (no quotes), the bracketed span of objects and arrays, and the literal span of numbers and null. Whitespace is tolerated. A field written without the `{"value": ...}` wrapper is also accepted.
- Classification: scores over the 4 known types are normalized to probabilities p. The result is `(argmax, p1 * (0.5 + 0.5 * (p1 - p2)))`, so a clear winner stays high and a near tie falls. Unknown keys are ignored and negatives are clamped. Empty or all-zero gives `(None, 0.0)`.
