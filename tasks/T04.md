# T04: Ingest: PDF/image -> normalized image + text layer

## Description
Render PDFs with PyMuPDF (150-200 DPI, long side <= ~1600px) and extract the text layer when present; resize PNG/JPG to the same limit; support multi-page PDFs; detect file type by magic bytes, not by extension.

## Acceptance criteria
- [x] All 10 files in `document-tests/` load
- [x] Unit tests with small generated PDFs/images

## Files
- `src/medextract/ingest.py`
- `tests/test_ingest.py`

## Notes
- Implemented `src/medextract/ingest.py` (API as in the task) and `tests/test_ingest.py` (47 tests, all passing; `ruff check` clean).
- Uses `import pymupdf` instead of `import fitz`: same library, but PyMuPDF 2.0 warns on the `fitz` alias.
- Behaviour decisions:
  - `text_layer` covers only the rendered pages (first `max_pages`), so it matches `images`.
  - Encrypted PDFs are rejected only when they cannot be opened with an empty password. Owner-password-only PDFs still load.
  - Multi-frame TIFFs return one image per frame, up to `max_pages`. Other formats use the first frame only.
  - Transparency is composited on white. Grayscale and palette images are converted to RGB.
- Real fixtures (all 10 load, long side 1600 px at 200 DPI for A4/A5 PDFs):

- Text layer quality: the Vietnamese and Thai PDF text is clean. Vietnamese diacritics are intact (NFC-stable, no U+FFFD). Thai text is intact, but digits are Thai numerals (e.g. "๒๑๔", "๕๐๒๐๐") and the years are Buddhist era ("๒๕๖๗" = 2567 BE), so the normalizer must handle both. Table cells come out one per line, not as rows, so the VLM image is still needed for line-item alignment.
- Image-only inputs (06, 08, 10) have no text layer. Those documents depend entirely on the VLM.
- Loading a PDF takes about 0.03 to 0.13 s for these fixtures. The PNG and JPG fixtures are 1.5 MB each, and downscaling them takes about 0.05 s.
- Known limit: PDF rendering uses the built-in Helvetica font for generated test PDFs, which cannot draw Vietnamese diacritics. Tests therefore use ASCII text only. This does not affect the real fixtures, which embed their own fonts.
