# T10: Prompts: classify + 4 extraction prompts

## Description
A classify prompt that scores all 4 types. One extraction prompt per type with a JSON schema, anti-hallucination rules ('null if not visible'), verbatim transcription with no translation, and an `evidence` snippet (original text) for each field.

## Acceptance criteria
- [x] Prompts contain no data specific to the 10 test files
- [x] Snapshot tests for the prompts

## Files
- `src/medextract/prompts/`

## Notes
- Files: `prompts/builders.py` (all prompt text and builders), `prompts/__init__.py` (re-exports). Tests: `tests/test_prompts.py` (23 tests).
- `SYSTEM_PROMPT` holds every shared rule (no guessing, verbatim text, confidence anchors, JSON-only). Callers must send it as the system message, so the user prompts stay short.
- Extraction schema is generated from `FIELD_SPECS` and `ITEM_MODELS`/`Diagnosis` keys. Each field kind gets a one-line value-shape hint.
- Text hint is truncated to 6000 chars with a marker. It is labelled as machine-extracted and fallible, and told not to add fields.
- Unknown `document_type` raises `ValueError`.
